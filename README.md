# Galgame for 1

**大一第一次尝试做的游戏** —— 一个使用 Ren'Py 8.5.3 开发的视觉小说（Galgame）项目。

## 说明

- **引擎**：Ren'Py 8.5.3（SDK 位于 `D:\Tools\renpy-8.5.3-sdk`）
- **项目结构**：
  - `game/` —— 游戏本体（脚本、立绘、背景、音频、界面）
  - `_raw_art/` —— 原始美术素材（PNG 立绘源文件）
  - `美术生成指南.md` / `美术生成指南-中文版.md` —— 美术素材生成指南

## 运行

用 Ren'Py SDK 打开本目录即可启动游戏；或在 `game/` 目录下运行 Ren'Py 引擎。
